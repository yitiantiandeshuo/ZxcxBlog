# 开发验证记录

## BLOG-01：博客与在线写作

- 风险：高。范围包含管理员认证、文章草稿、并发写入、文件访问和备份。
- 验收：公开只读取已发布文章和其图片；管理操作校验 Cloudflare Access 身份；冲突保存不得覆盖较新文章；备份可在隔离数据库恢复。
- 已验证：Node 内置测试（含真实内存 SQLite 和隔离 R2 模拟）、Wrangler 本地 D1 迁移、Worker dry-run 构建、本机 Worker 首页及未认证访问检查、备份转 SQL 与隔离 SQLite 恢复。
- 独立审查：请求 gpt-6.1-terra high；首轮发现草稿图片暴露和并发覆盖，已修复并补测试；同一审查者复查确认两项阻塞已解决。复查时的两项非阻塞建议（图片引用精确匹配与 404 禁止缓存）随后已处理并补测。
- 线上状态：已创建专用 D1 数据库和 R2 存储桶，初始迁移成功；Worker 已部署，首页匿名返回 200；管理页和 API 匿名跳转 Access 登录。Access 应用复用仅允许站长邮箱的现有策略。
- 待验证：用户视觉验收、真实账号登录及写作、线上图片上传和完整备份恢复。

## BLOG-02：图片缓存与安全加固

- 风险：高。公开状态、私有图片、R2 操作费用和缓存一致性。
- 验收：先检查 D1 发布状态；安全隔离内部缓存与浏览器缓存；撤回后不公开图片；非法请求尽量不读取 R2；无付费依赖。
- 本地结果：Node 12 项通过；隔离 Wrangler D1/R2 本地运行时 GET、HEAD、查询参数和撤回通过；Wrangler dry-run 构建通过。Node 测试使用模拟 Cache API；真实全球缓存及实际节省费用未验证。
- 独立审查：gpt-6.1-terra high 首轮提出媒体错误 no-store，已修复；复查无阻塞。管理员预览安全头的独立修复另行审查无阻塞，并补充 R2 元数据覆盖回归测试。
- 账户只读检查：R2 令牌页面当时未列出 Account API 或 User API 令牌；先前确认 r2.dev 已禁用、无自定义域名、Workers 列表只有本博客。不能排除其他类型的凭据或未来新增入口。
- 待验收：真实 Cloudflare Cache API 与 Access 组合、不同数据中心缓存命中、R2 实际操作量、用户线上登录及上传。尚未部署 BLOG-02。
